# Confluence Change Analyzer

Chrome-расширение (Manifest V3) для работы с историей изменений страниц Confluence:
находит правки по задаче Jira, дате или автору из таблицы «История изменений»,
обводит их красной рамкой прямо на странице и выгружает в Word.

> Подробная инструкция с картинками — кнопка **?** в окне расширения
> или [`docs/instruction.pdf`](docs/instruction.pdf). Полный README — в работе.

## Быстрый старт

```bash
npm install
npm run build        # сборка в dist/
npm run dev          # сборка с пересборкой при изменениях
npm run test:e2e     # сквозные тесты в Chromium (после npm run build)
```

Установка в Chrome: `chrome://extensions` → «Режим разработчика» →
«Загрузить распакованное расширение» → папка `dist/`.

## Возможности

- Разбор таблицы «История изменений» в документе: версия, дата, автор, описание и его цвет, задачи Jira.
- Фильтры «Дата изменения», «Автор», «Артефакт Jira» (по «И»); фильтры можно отключать в настройках ⚙.
- Подсветка правок цвета выбранной записи; автоматическое раскрытие свёрнутых блоков.
- Работает в режиме просмотра и редактирования (Confluence Server / DC и Cloud).
- Экспорт в Word: найденные правки по пунктам (где находятся и сам цветной текст) или таблица истории.
- Всё выполняется локально в браузере, данные никуда не отправляются.
